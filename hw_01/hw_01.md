# Part 2 
## Cost of fork()

Usage: `./part2 <size-in-MB>`

The program `./part2` loops 10,000 times to compute the average cost of a `fork()` call. In each loop, an array of `<size-in-MB>` MB is allocated and initialized and then a timer is started. `fork()` is called and the parent waits for the child using `waitpid()`.
