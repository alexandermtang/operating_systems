## Determining L2 Cache Parameters

**Usage**: `./part1`

a. **Cache Block/Line Size** - 64 B. The cache block size was determined by allocating an 8 MB array and linearly iterating over the array multiple times in "strides" of 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, and 1024 bytes. Each of these iterations were measured using a microsecond timer. The largest difference in times was between 64 and 128 B since "strides" of 64 B or more required fetching a new block for every memory access. ## Cost of fork()

**Usage**: `./part2 <size-in-MB>`

The program `./part2` loops 10,000 times to compute the average cost of a `fork()` call. In each loop, an array of `<size-in-MB>` MB is allocated and initialized and then a timer is started. `fork()` is called and the parent waits for the child using `waitpid()`.
